### Inline code info strings

Inline code spans may carry unquoted info strings.

```````````````````````````````` example
Ruby code: `Object.new`:ruby
.
<p>Ruby code: <code class="language-ruby">Object.new</code></p>
````````````````````````````````

Inline code spans may carry quoted extended info strings.

```````````````````````````````` example
Ruby code with extended fence info: `Object.new`:"ruby lineno=5"
.
<p>Ruby code with extended fence info: <code class="language-ruby">Object.new</code></p>
````````````````````````````````

Inline code spans may carry empty info strings, which are normalized away.

```````````````````````````````` example
Empty info: `x`:
.
<p>Empty info: <code>x</code></p>
````````````````````````````````

Unterminated quoted inline code info strings stop at the line ending.

```````````````````````````````` example
Before `x`:"ruby lineno=5
after
.
<p>Before <code class="language-ruby">x</code>
after</p>
````````````````````````````````
